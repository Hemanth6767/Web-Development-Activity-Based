Website Mockups Compilation

Welcome to the Website Mockups Compilation! This repository contains a collection of clean, modern, and responsive front-end UI mockups designed for various e-commerce niches.

📑 Included Projects

This compilation features three distinct website designs, each tailored to a specific industry:

1. Sweet Bakery 🎂

A warm and inviting landing page designed for a local bakery or pastry shop.

Theme: Warm colors (browns, creams, and oranges) to evoke a sense of freshly baked goods.

Key Features:

Clear navigation menu.

Hero section with a prominent call-to-action (CTA).

Product showcase grid (Chocolate Cake, Strawberry Cake, Cupcakes) with pricing and order buttons.

Special promotional banner ("Special Weekend Offer!").

"About Us" section and a detailed footer with contact information.

2. Smart Shop 🛍️

A versatile and clean storefront template suitable for general retail and fashion.

Theme: Trustworthy and crisp colors (blues, whites, and bright accents).

Key Features:

Welcoming hero banner.

Product grid highlighting fashion and utility items (T-Shirt, Sports Shoes, Travel Bag).

Discount badges seamlessly integrated into product cards.

"Special Festival Offer!" section to drive sales.

Standard footer layout with business contact details.

3. ElectroHub 💻

A sleek, modern design tailored for a consumer electronics and tech store.

Theme: Dark and high-tech aesthetics (deep blues, blacks, and vibrant blue accents).

Key Features:

Impactful hero section highlighting "Next-Gen Technology".

Dedicated promotional banner for a "Mega Electronics Sale".

Grid layout for featured products (Laptop, Smartphone, Headphones, Smartwatch) complete with specs, ratings, and discount tags.

Product Comparison Table: A detailed grid comparing specifications (Price, Processor, Memory, Storage, Display) across different devices.

Detailed product list outlining features for specific items.

🛠️ Design Features

Responsive Layouts: Designed to scale beautifully across different screen sizes.

Modern UI/UX: Utilizes clean typography, subtle borders, and consistent spacing for a professional look.

E-commerce Ready: Includes essential e-commerce components like pricing, discount badges, "Buy Now" buttons, and comparison tables.

🚀 How to View

The mockups are currently compiled into a single document format (Website Mockups Compilation.pdf / HTML equivalent). Simply open the file in your preferred web browser or PDF viewer to see the full designs.
